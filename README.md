## 🎮 1. 게임 소개 (Overview)

**DO NOT PLAY THIS GAME**은 윈도우 95 / 윈도우 98 및 초기 인터넷 감성의 레트로 OS 환경을 배경으로 한 **싱글 플레이어 데스크톱 브라우저 탄막 생존 게임**입니다.

플레이어는 지속적으로 쏟아지는 탄막을 회피해야 하며, 주기적으로 컴퓨터 시스템 자체가 플레이어를 방해하고 직접 공격하는 **다양한 시스템 오류 및 방해 공작(Interference Events)** 속에서 가능한 오래 살아남아야 합니다.

* **장르**: 싱글 플레이어 레트로 탄막 생존 (Bullet-Hell Survival)
* **플랫폼**: 웹 브라우저 (Chrome, Edge, Firefox 등)
* **기술 스택**: HTML5 Canvas, Vanilla JavaScript (ES6+), Web Audio API, Pure CSS (Zero External Dependencies)
* **지원 언어**: 🇰🇷 한국어 / 🇺🇸 English (100% 실시간 언어 전환)

## ⚔️ 3. 핵심 시스템 (Core Gameplay Systems)

### ① 지속 탄막 엔진 (Continuous Bullet Engine)
* 플레이어는 항시 화면에 쏟아지는 탄막을 피해야 합니다.
* **다양한 탄막 패턴**: 부채꼴 확산탄 (Fan Shot), 플레이어 조준 스트림탄 (Basic Stream), 측면 압박탄 (Side Pressure), 상공 파일 낙하탄 (Falling Files), 경고 레이저 (Warning Laser), 벽면 바운딩 오류창 (Bouncing Error)
* 생존 시간에 따라 탄막 밀도와 속도가 유기적으로 상승합니다.

### ② 이벤트 디렉터 & 0.8초 사전 경고 (Event Director & Warning Telegraph)
* 약 10초 주기로 **하나의 방해/공격 이벤트**가 활성화됩니다.
* 이벤트 발생 0.8초 전, 화면 상단에 **경고 배너 및 사운드**가 출력되어 플레이어가 대비할 수 있도록 신호를 제공합니다.
* 이벤트 중에도 기본 탄막 회피가 유지되며, 이벤트 특성에 맞춰 탄막 밀도가 공정하게 자동 조절됩니다.

### ③ HP_FIX.EXE 체력 회복 아이템 (Health Item System)
* 방해 이벤트를 돌파할 때마다 일정 확률로 아레나에 초록색 의료 십자가 모양의 **`HP_FIX.EXE`** 레트로 실행 파일 아이콘이 드롭됩니다.
* **드롭 확률**: 일반 돌파 시 **40%**, 무피격 클린 돌파 시 **65%**
* **효과**: 획득 시 **HP +20 회복** (최대 체력 100 초과 불가)
* 6.5초 후 자연 소멸하므로 탄막을 피하며 전략적으로 회수해야 합니다.

### ④ 연속 돌파 (Streak) & 랭크 시스템 (Ranking)
* 피격당하지 않고 이벤트를 연속으로 돌파할 때마다 **STREAK 보너스 점수**가 가산됩니다.
* 게임 오버 시 생존 시간, 최종 점수, 돌파 횟수, 최대 연속 돌파 기록을 종합하여 **F ~ S 랭크**와 유머러스한 평가 코멘트를 산출합니다.

## 💥 4. 22종 방해 & 공격 이벤트 일람 (Interference Events)

본 게임에는 시스템 UI를 무기화하거나 시야 및 조작을 방해하는 **22가지 독창적인 이벤트**가 수록되어 있습니다.

### 🔴 직접 공격형 이벤트 (ATTACK)
1. **ZIP 폭탄 (`Zip Bomb`)**: 필드에 생성된 압축 파일(`archive.zip`)이 카운트다운 후 사방으로 미니 파일 파편(`.txt`, `.dll`, `.exe`, `.bmp`)을 폭발 방출합니다.
2. **오류 레이저 (`Error Laser`)**: 가장자리에 오류창 포탑이 생성되어 점선 조준선 예고 후 치명적인 고전압 글리치 레이저를 발사합니다.
3. **백신 검사 (`Antivirus Scan`)**: 플레이어를 바이러스로 인식(`THREAT DETECTED: PLAYER`)한 레이더 스캔 필드가 화면을 훑고 지나갑니다.
4. **Delete 키 (`Delete Key`)**: 플레이어 위치에 조준선이 고정된 후, 거대한 레트로 3D `[ DELETE ]` 키캡이 상공에서 수직 낙하 강타합니다.
5. **방화벽 (`Firewall`)**: 불타는 벽돌 방화벽이 화면을 가로지르며, 초록색 개방 포트(`PORT OPEN`)를 찾아 안전하게 통과해야 합니다.

### 🟡 시야 및 UI 왜곡형 이벤트 (VISION / UI)
6. **팝업 지옥 (`Pop-up Hell`)**: 닫아도 계속해서 시야를 가리는 오류 팝업창들이 화면 곳곳에 생성됩니다.
7. **가짜 업데이트 (`Fake Update`)**: "중요 시스템 업데이트 설치 중..." 창이 화면 중앙을 가리고 43% $\to$ 99% $\to$ 업데이트 실패 성공으로 이어집니다.
8. **신호 없음 (`No Signal`)**: CRT 모니터의 지지직거리는 아날로그 노이즈와 스캔라인 오버레이가 발생합니다.
9. **알림 폭탄 (`Notification Spam`)**: 우측 하단에서 윈도우 트레이 알림 풍선이 무차별적으로 쏟아져 시야를 차단합니다.
10. **제목줄 낙하 (`Title Bar Drop`)**: 게임창 상단 제목 표시줄이 분리되어 바닥으로 낙하하여 물리 장애물이 됩니다.
11. **작업표시줄 확장 (`Taskbar Malfunction`)**: 하단 작업 표시줄이 비정상적으로 치솟아 플레이 가능 영역을 침범합니다.
12. **UI 침공 (`UI Invasion`)**: 버튼, 체크박스 등 시스템 UI 요소들이 위에서 비처럼 쏟아져 내립니다.
13. **색상 오류 (`Color Error`)**: 아레나 전체가 16색 왜곡 레트로 팔레트로 전환됩니다.
14. **화면 찢김 (`Screen Tearing`)**: 실제 오프스크린 캔버스 수평 슬라이스 변위로 화면이 불규칙하게 찢어집니다.

### 🟣 조작 및 커서 교란형 이벤트 (INPUT)
15. **조작 반전 (`Reversed Controls`)**: 상하좌우 이동 키가 일시적으로 반전됩니다 (`W↔S`, `A↔D`).
16. **커서 공격 (`Cursor.exe`)**: 거대한 시스템 마우스 커서가 플레이어를 집요하게 추격합니다.
17. **마우스 잔상 (`Mouse Trail`)**: 윈도우 마우스 포인터 잔상 효과가 필드 전역에 흩뿌려집니다.

### 🔵 공간 압박형 이벤트 (SPACE / WINDOW)
18. **화면 축소 (`Window Shrink`)**: 게임 뷰포트 창이 0.75배로 축소되어 좁은 공간에서 탄막을 회피해야 합니다.
19. **흔들리는 창 (`Moving Window`)**: 게임 창 전체가 모니터 바탕화면을 둥둥 떠다니며 표류합니다.
20. **창 잔상 (`Window Ghost`)**: 게임 창의 복제된 유령 잔상들이 어긋나게 겹쳐 혼란을 줍니다.
21. **스크롤바 오류 (`Scrollbar Malfunction`)**: 레트로 스크롤바가 상하좌우에서 안쪽으로 파고들어 이동 공간을 압박합니다.

### 🟢 저강도 유머 배경 패턴 (VISUAL / BACKGROUND)
22. **블루스크린 (`Blue Screen`)**: **피해가 없는 특별 패턴**으로, 캔버스 배경이 고전 패러디 BSOD("치명적인 문제가 발생했습니다. 안타깝게도 게임은 계속됩니다.")로 전환됩니다.

## 🛠️ 5. 개발자 디버그 툴킷 (Developer Debug Toolkit - `F2`)

본 게임에는 시연 및 밸런스 검증을 위한 **강력한 윈도우 98 스타일 인게임 디버그 패널**이 내장되어 있습니다.

* **상단 액션 바**:
  * `🔄 전체 초기화 (RESET ALL)`: 모든 테스트 상태 및 탄막/이벤트 즉시 초기화
  * `⏹ 이벤트 종료 (END EVENT)`: 현재 활성 이벤트 강제 종료 및 클린업
  * `⏸ 일시정지`, `💚 HP 완전 회복`, `💔 -20 HP 피해`, `🛡️ 무적 모드 ON/OFF`
  * `👁️ 투명도 조절 (100% / 70% / 40%)`, `_ 창 최소화`, 부드러운 드래그 이동 지원
* **방해 이벤트 실험실 (Event Lab)**:
  * 22종 전 이벤트 검색, 카테고리 필터링 (`공격`, `시야`, `조작`, `공간`, `창`, `시각`)
  * `EASY`, `NORMAL`, `HARD` 난이도별 즉시 실행 테스트
* **자동 순차 검증기 (Sequence Runner)**:
  * `▶ 전 이벤트 자동 실행 (RUN ALL EVENTS)`: 22종 모든 이벤트를 순차적으로 자동 테스트
  * `▶ 난이도별 전 변형 테스트 (TEST ALL VARIANTS)`: 총 66개 케이스 순차 검증
* **탄막 조합 실험실 (Bullet Lab)**:
  * 탄막 난이도 고정 (`끄기`, `쉬움`, `보통`, `어려움`, `혼돈`)
  * 특정 탄막 패턴 단독 테스트
